# 💥 Web Bruteforcer

Автоматический перебор паролей к формам входа.

## Возможности

- Автопоиск форм входа на странице
- Обход CSRF токенов
- Определение успешного входа по 6 признакам
- Многопоточность (до 30 потоков)
- Встроенный словарь из 66 популярных паролей
- 4 режима перебора
- Сохранение найденных учётных данных

## Технологии

- Python 3.11
- requests
- BeautifulSoup
- re

## Установка

```bash
git clone https://github.com/Oncillaa/web-bruteforcer.git
cd web-bruteforcer
pip install requests beautifulsoup4
python web_bruteforcer.py
```
## Использование

- Запусти программу
- Выбери режим перебора
- Введи URL страницы входа
- Укажи логин или словарь
- Жди результат

## ⚠️ Только для образовательных целей

## 🔧 Как это работает

1. Находит форму входа на странице
2. Определяет поля логина и пароля
3. Обнаруживает CSRF токены
4. Перебирает пароли с задержкой
5. Определяет успех по редиректу и ответу

## ⚠️ Ограничения

- Не обходит капчу
- Работает только с HTML формами
- Может заблокировать IP при частых попытках
